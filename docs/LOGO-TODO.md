## Logo İndirme Yöntemi

1. Her sağlayıcının resmi web sitesine git
2. "Basın Kiti", "Press Kit", "Media", "Hakkımızda" veya "Assets" bölümlerini ara
3. Logo dosyalarını indir (tercihen SVG, yoksa yüksek çözünürlüklü PNG)
4. Dosyaları ilgili klasörlere kaydet
5. `app.js` içindeki `providerLogos` objesini güncelle

## Logo Kullanım Kuralları

- Her şirketin logo kullanım kılavuzuna uyulmalı
- Logoları deforme etme, renk değiştirme yapma
- Minimum boyut gereksinimlerine dikkat et
- Beyaz/şeffaf arka plan kullan
